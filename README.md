# 🛒 Mis Compras - Lista Inteligente v3

> Aplicación Web Progresiva completa para organizar tus compras.

## ✨ Características

- ✅ Cantidad y unidades (kg, L, pack…)
- 🏷️ Categorías con filtro
- ✏️ Editar productos
- 📋 Múltiples listas
- 📤 Compartir lista
- 🛒 **Modo Compra** (pantalla grande para el súper)
- 🔍 Búsqueda de productos
- ⠿ **Drag & drop** para reordenar
- 💡 Sugerencias / historial de productos frecuentes
- 🌙 Modo oscuro (opaco) / Claro (con brillo)
- 🎨 Fondos distintos por cada ventana
- 🔊 Sonidos + 📳 Vibración (opcionales)
- 💾 Exportar / Importar JSON
- 📱 Instalable · 📶 Offline

## 📱 Instalar

**Android:** Chrome → ⋮ → Instalar app  
**iPhone:** Safari → Compartir → Agregar a pantalla de inicio

## 🚀 Uso rápido

1. Agrega productos con cantidad y categoría
2. Arrastra para reordenar
3. Entra a **🛒 Comprar** en el súper y tacha con un toque
4. Comparte la lista cuando quieras

Proyecto de uso libre. 🛒✨
