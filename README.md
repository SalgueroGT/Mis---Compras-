## ✨ Características (v2)

- ✅ **Cantidad y unidades** (kg, L, pack, docena…)
- 🏷️ **Categorías** (Frutas, Lácteos, Limpieza, etc.)
- ✏️ **Editar productos** fácilmente
- 📋 **Múltiples listas** (Supermercado, Farmacia, Ferretería…)
- 📤 **Compartir lista** por WhatsApp / cualquier app
- 📊 **Contadores en tiempo real**
- 🔍 **Filtros y orden** (recientes, A-Z, por categoría)
- 🌙 **Modo oscuro**
- 🔊 **Sonidos** (activables/desactivables)
- 📳 **Vibración** (Android)
- 💾 **Guardado automático** + Exportar/Importar JSON
- 📱 **Instalable como App** (Android e iOS)
- 📶 **Funciona SIN internet**
- 🎨 **Diseño moderno** con Glassmorphism
- 🔄 **Migración automática** desde la versión anterior

---

## 📱 Cómo instalar

### Android (Chrome)
1. Abre la URL en **Chrome**
2. Toca los **3 puntitos** ⋮
3. Selecciona **"Instalar app"** o **"Agregar a pantalla de inicio"**

### iPhone (Safari)
1. Abre la URL en **Safari**
2. Toca el botón de **Compartir** 📤
3. Selecciona **"Agregar a pantalla de inicio"**

---

## 🚀 Cómo usar

1. Elige o crea una **lista**
2. Escribe el producto, cantidad y unidad
3. Selecciona la **categoría**
4. Toca **+** o presiona Enter
5. Marca con **✓** cuando lo compres
6. Edita con **✎** o elimina con **✕**
7. Comparte la lista completa con el botón **📤**
